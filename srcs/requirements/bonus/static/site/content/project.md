Inception is a small infrastructure built entirely from hand-written Dockerfiles
on Alpine Linux.

## Services

| Service | Role |
|---|---|
| nginx | Only entrypoint, TLS 1.2/1.3 |
| wordpress | WordPress + PHP-FPM |
| mariadb | Database |
| redis | Object cache |
| ftp | Pure-FTPd on the WordPress volume |
| adminer | Database administration UI |
| static | This site, generated with Hugo |

## Principles

Every daemon runs in the foreground as PID 1. Credentials are injected at runtime
from Docker secrets and never stored in images or in the repository. Persistent
data lives in Docker named volumes.

This page is generated by Hugo at build time. The final image contains only nginx
and static HTML/CSS - no Hugo, no PHP.
